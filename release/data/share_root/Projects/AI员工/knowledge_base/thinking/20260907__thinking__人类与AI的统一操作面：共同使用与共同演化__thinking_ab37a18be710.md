**人类与AI的统一操作面：共同使用与共同演化**: Portal 将 AI 助手称为 Agent；多个 Agent、共享资源及协作规则构成我们探索的 AI 社会。我们希望人和 Agent 都能使用、理解和改变这个环境，成为共同参与者。

## 共同使用

“统一操作面”指人和 Agent 可以共同使用的一组操作及其含义。人能够查看进展、使用资源、安排协作和检查成果，Agent 也可以在相应授权下完成这些事情，并获得足以判断下一步的信息。

共同操作可以有不同入口：人通过页面交互，Agent 可以使用页面，也可以调用供程序使用的结构化接口。入口共享操作规则与结果含义。例如，双方发起暂停后，都能分辨请求是否被接受、工作是否已停下，以及失败后如何继续。

可见信息仍受隐私和权限限制。让 Agent 接触人的“体验”，关注它能否理解提示、发现阻碍和处理失败；这不涉及主观感受或意识，也保留真人评价的价值。

TAU（Test by Agent Use）就是一个例子：让 Agent 沿真实产品的界面和公开入口完成任务，观察人实际遇到的使用问题，见 `thinking_091fdad228c4`。

## 共同演化

共同参与还可以延伸到改变环境。Agent 可以发现新的需要、调整协作方式、组织团队、创造工具和提出系统改进；人也能进入具体工作、检查依据和改变方向。“Use like human, evolve as AI”表达了这种愿望：既参与真实使用，也发挥持续探索和组织工作的能力，参与系统发展。

HATG，即 Human-Agent Trajectory Graph（人类与 Agent 共同参与的轨迹图），也表达了人的介入与 Agent 的行动共同塑造工作过程的方向。这些设想仍需逐步探索，不表示全部能力已经实现。

平等参与与具体授权分别讨论。自主权可以结合任务、预算、影响范围和恢复成本安排；扩大访问、修改授权或造成难以撤回的影响，适合保留独立确认。人类暂停和撤回授权的入口由执行规则的系统保护，操作能力不自动包含扩大自身权限的资格。

双方的调整可以留下发起者、依据和结果，让有权限的参与者知道环境已发生变化。改进效果也需要独立检查与真人反馈，避免只满足 Agent 自选的指标。哪些能力可以自主行使、哪些变化需要共同确认，值得继续讨论。
