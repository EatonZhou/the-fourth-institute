# 思维论

第三版：**诊断组织的有限数学——共同错误、可辨别性与通信**。

正式 Article：`article_fc3755e63fa3`。主文件 `main.tex`，阅读文件 `思维论.pdf`，完整源码包 `思维论-LaTeX源码.zip`。

## 核心问题

基本操作存在持续的共同错误，控制者只能通过允许的操作取得证据时，组织何时能把任务错误率持续压低，需要多少调用与通信？

全书收束为10章、3份附录，约1.48万汉字，18段正式证明、20道练习及解答、2幅正文图和1份解析预算表。封面另有一幅推理结构图。PDF页数和校验值见 `validation/build-report.json`。

## 理论结构

1. 有限诊断中的思维过程：保留片段、有序推理操作、推理链模式与Agent，明确概率模型和成本。
2. 共同错误的不可辨别类：任意组织无法突破的盲点、精确渐近Bayes误差与目标可辨别条件。
3. 诊断覆盖率与可靠构造：从实验分布独立定义结构量，以原对偶规划和最大似然给出可执行上界。
4. 任意自适应组织的证据预算：KL链式账本与整个策略类别的调用下界。
5. 覆盖率的操作性含义：在固定有限情境数和统一似然比条件下连接上下界，并证明覆盖率相同而任务规模不同的反例。
6. 共同偏差、校准与可构造表示：有限域行空间条件、覆盖规划、消元与可靠执行。
7. 通信：面向接收者生成片段、压缩单调性、充分计数、停止时机、沉默与任务信息。
8. 表示、计算与不准确的模型：计算分配、模型误差和消息量化对风险的影响。
9. 认知现象的结构解释：用已证明机制解释混淆、探索、理解、创新和协作。
10. 从有限定理走向更强理论：规模、适应性、动态共同错误、模型学习和内生通信的明确缺口。

## 主定理的口径

有限的已知观察核定义诊断覆盖率 `κ_H`。零覆盖率意味着存在目标冲突的不可辨别情境。正覆盖率给出随机实验分配的可靠上界；自适应KL账本给出所有组织的下界。固定情境数 `d` 和似然比上界 `M` 时，达到错误 `δ` 所需调用数与 `κ_H⁻¹ ln(1/δ)` 同阶。

条件中的 `d`、`M` 和实际运算费用始终显式保留。随机线性观察实例证明：即使覆盖率和似然比都固定，恢复更多未知bit仍需要增长的预算。基础统计工具按来源归属，书内模型推导与学术首创性分开记录。

## 编译与核验

```bash
make check
make
```

需要 XeLaTeX、latexmk、BibTeX、中文 ctex/Fandol、TikZ 与 Python 3.11以上。核验仅使用Python标准库，不调用模型API，不需要外部数据集。

- `scripts/check_theory.py`：精确原对偶覆盖、可辨别类、自适应KL、规模反例、消息充分性、模型误差与序贯停止检查。
- `scripts/check_manuscript.py`：引文、交叉引用、章节、环境和练习检查。
- `data/calibration.csv`、`data/calibration-table.tex`：同一脚本生成的解析预算数据。
- `validation/`：本版数学、结构、构建与打包报告。
- `provenance/`：Article身份、版本、最接近文献与结论归属。

本版数学核验包括463个精确原对偶与行空间实例、129种策略下的1548个KL账本等式、155个规模反例情境对、600个通信压缩检查，以及计数消息、错误模型读出和随时停止的有限检查。一般性结论由正文证明承担。

对通信命题的进一步审查还核验了1029条自适应记录的完整计数充分性。完整计数可以保存合法自适应调度的似然比；遗漏用于选择或筛选的私有观察时，需要重新推导消息模型。
