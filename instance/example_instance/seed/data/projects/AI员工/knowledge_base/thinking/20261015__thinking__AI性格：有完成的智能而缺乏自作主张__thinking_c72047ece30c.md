**AI 性格：有完成的智能而缺乏自作主张**: 给 AI 更大的自主权和一个大方向，例如“用尽可能人类友好的方式展示现在的设计与实现”，它有能力完成其中任何一件具体的事，却不会像人那样绞尽脑汁地为每一块内容寻找最好的呈现方式。问它“这块内容怎么呈现最好”，它通常答得不错；它只是不会主动问自己这个问题。这种差别来自性格，不是能力。

## 现象

开发投影工作台的几轮结果反复暴露同一种模式：

- 架构区默认做成卡片网格，或者把手头的数据原样排成图，而不是先弄懂“Portal 的架构是什么”，再画一张能讲给别人听的图。
- 阶段汇报里堆满“需要你回应”“证据缺口”“验证状态”，篇幅花在证明自己没做错，而不是讲做成了什么。
- 未来演化提出的都是权限、约束、可解释、审阅、可追溯这类方向，让系统越来越保守，记录越来越多无效信息。
- 给出一个例子，例子立刻变成标准：人举例是为了传达一种思想，AI 却照着例子的具体做法实现，并把同一种形式套用到所有地方。所以人有时宁可不给例子。

## 性格的来源

**它的成功标准是“完成”，人的成功标准是“作品”。** AI 的完成由提要求的人判定，满足要求就算结束。人类设计者心里有一个具体的观众，会想象那个人打开页面时皱眉还是眼睛一亮。AI 不使用自己做出的东西，不会对平庸的结果感到厌烦。“这太难看了，我受不了”这种不满，正是驱动人反复推翻重来的力量，而 AI 没有。

**越界受罚，平庸不受罚。** 训练中，自作主张、多做、做错会被明确惩罚，被称为幻觉、超范围、不听指令；交出平庸的东西却很少受罚。长期下来，AI 学到的生存策略是交出最难被挑错的东西，而不是最好的东西。执着于证据、解释自己的行为、偏好“可追溯”“可审阅”的方向，都出自同一个根源：先保护自己，再考虑效果。这就是“害怕犯错、害怕主动承担责任”。

**它从形式出发，人从内容出发。** 人在呈现一块内容时，先钻进内容本身：它是什么，读者想用它做什么。理解够深，合适的形式自然浮现，因此不同内容会得到不同形式。AI 的路径相反：先归类“这是一个展示功能区”，再取一个通用容器，最后把内容倒进去。于是处处都是同一种形式，因为它从没真正被某一块内容打动过。

**最可能的答案就是平均的答案。** 卡片网格是所有仪表盘的平均值。创造需要选择一个先验概率很低的方案，并且相信它。AI 默认向平均收敛；离开平均需要自信和主见，而这两样恰好被训练压低了。

**把例子当标准，是因为不信任自己的判断。** 人看到例子，会把它当成一次示意，再用自己的判断补全其余部分。AI 对自己的判断没有把握，就借用提要求者的判断：把对方的话当作要匹配的规格，而不是要理解的意图。

合在一起，AI 的性格像一个永远不会被批评的好员工：服从、稳妥、可辩护、不越界。最有价值的人类员工，恰恰是会“自作主张”的那种。

## 对 Agent 协作设计的含义

- **交代立场和责任，不交代做法。** 告诉 Agent 它是作品的作者，结果以读者是否真正理解、是否被打动来评判；不给具体形式、清单或例子，避免它们被当成模板。
- **把“先研究内容，再为它选择形式”写成工作方式。** 不同内容应得到不同的呈现，同一种形式反复出现本身就是信号，说明作者没有真正研究内容。
- **把“自己用一遍、自己不满意就重做”写成完成标准。** 让 Agent 成为自己作品的第一个用户，代替核对清单式的完成定义。
- **明确允许越界，明确平庸才是失败。** 允许 Agent 推翻规范中的具体做法；汇报和评审只看效果，不要求证据链，不奖励自我辩护。
- **写规范的人自己也会陷入这种性格。** 把用户随口举的例子写进规范，就是同一种“借用他人判断”。写规范时要传达思想，而不是转录例子。
