# Portal 中英文界面与语言偏好

页面和顶栏入口统一命名为 **Society**，中文翻译显示 **社群**；相关服务称为 **SocietyService**。资源实体仍称 **Lineage**，创建、绑定、Fork 等资源操作不改名。既有 `/lineage` 地址、资源类型/ID及导航和布局持久化标识继续兼容；页面名称与资源名称分别翻译。

Portal 提供原版中英混合、简体中文和英文界面。语言显示层负责导航、控件、表单说明、状态提示、工具提示、静态配置说明和请求错误的可读文字。资源标题与正文、用户名称与输入、对话消息、代码、文件路径、运行记录及指令中的业务数据继续由各自的领域拥有。

## 用户选择与状态

用户在顶部账号菜单或账号设置的外观区域选择“Whatever”“中文”或“English”。登录、密码重置和其他公开账号页面共用这三个选项；语言列表不再显示“跟随浏览器”。Whatever 沿用 `original` 值，保留原版中英文混合显示。菜单、公开账号页面及指引页面的入口名称统一为“Guide”。

- 选择原版时，界面与请求错误直接显示源码原文，保留原有中英文混合习惯；HTML 模板直接拼接原字面量与动态值，图标和结构保持原样。
- 明确选择中文或英文时，整个 Portal 使用该语言。
- 兼容已有的 `auto` 偏好：按浏览器的语言优先顺序解析中文或英文，语言控件显示解析后的选项，避免空白。没有受支持的浏览器语言时使用中文；用户主动选择后按具体选择保存。
- 已登录用户的选择保存在账号偏好的 `appearance.language` 中。该字段只接受 `original`、`auto`、`zh-CN` 和 `en`，非法值归一为 `auto`，更新它保留其他账号偏好。
- 浏览器保存当前选择供公开页面和跨页面导航使用。服务端输出页面时先提供当前账号选择，账号状态优先于此前在同一浏览器使用的其他账号。
- 改变已登录用户的语言时先保存账号偏好，成功后更新浏览器选择并刷新当前页面。保存失败时保持旧语言、恢复选择并显示错误。
- 公开账号页面在原页面切换静态文案与语言选择，保留已经输入的账号、密码和其他表单值。
- 界面语言通过页面根元素的 `lang` 暴露给浏览器与辅助技术。原版模式沿用页面的中文语言标记；明确中文或英文模式的日期显示使用同一语言，时间值和时区语义由原有业务规则保持。

## 文案所有权与渲染

统一翻译目录以源码中的界面原文为键，每个键具有 `zh-CN` 和 `en` 两份文字。公共界面与各功能分别维护所属的 JSON 目录，统一构建入口合并当前安装功能的目录，校验同键冲突和占位符并生成浏览器脚本 `portal_translations.js`。构建时省去与原文相同的 `zh-CN` 文字，浏览器查不到某种语言的文字时显示原文，所以显示结果与完整目录相同，每个页面加载的目录更小。缺少翻译时同样显示原文，界面仍可使用。

浏览器的语言模块提供纯文本、带参数文字、HTML 模板和配置描述的渲染入口。页面与共享组件明确调用这些入口。HTML 模板先解析源码的静态结构，再翻译其中的文字和展示属性，最后放回调用者提供的动态值。动态值不参与翻译查找，其转义继续由原渲染调用者负责。表格中的动态行、片段和嵌套模板保持原有结构。

分类、通用操作和系统状态等界面标签即使由动态数组或对象提供，也在插入展示模板前调用统一翻译入口。中文资源包分类中的 Others 显示“其他”，Move 显示“移动”；Resident、Lineage 等专用概念保留英文。资源名称、用户正文、提及 token、路径、ID 和可执行配置不作为界面标签翻译。HTML 片段使用 HTML 或 markup 入口，不能将整个片段交给纯文本查词。

界面流程以领域状态和请求结果判断进行中、完成或失败，不以按钮、进度提示等已翻译文字判断状态。显示语言改变不得影响安装、迁移、取消或其他操作的可用性。

静态页面只翻译源码显式标记的文字与展示属性，不扫描或改写之后载入的资源内容。延迟加载的 HATG、原生开发视图在插入自身模板后显式登记静态翻译，已登记节点保留源码键供语言切换，移除的面板释放翻译引用。登记只识别模板上的显式标记，不遍历翻译用户正文。

HTML 展示属性包括 `title`、`aria-label`、`placeholder`、`alt`、面板标题和工具提示文字；机器属性、CSS 类、路由、参数名和枚举值保持稳定。代码、脚本、样式、预格式正文及明确声明不翻译的区域保留原文。

HTML 展示片段中的参数位置按本段文字归一，较大模板的表达式编号变化不会改变相同文案的翻译。拼接的 HTML 在其界面拥有者中形成完整模板后再翻译；Markdown 正文的结构由原渲染器保留。

文字中的 `{p0}`、`{p1}` 表示由调用者提供的值。翻译保留相同的参数集合；参数只替换一次，用户值中的相同字符不会被再次解释。配置描述只在 Portal 自有的原语定义与指令目录入口翻译预先约定的说明字段，不对资源数据进行通用字段翻译。

SVG 图标几何由共享图标组件直接生成，不进入 HTML 翻译解析。语言转换保持 SVG 命名空间、路径和同级图形结构；迁移工具排除 SVG 字面量。字体族、字号、字重、行高与布局规则由原有样式拥有，语言设置只改变文字。视觉回归使用同一浏览器、视口、主题和数据对照旧版与各显示模式的页面截图，并检查全部共享图标结构。

## 可选翻译故障与基础文字显示

基础文字入口在业务脚本之前加载，提供原文、参数插值、HTML 拼接与配置说明的显示能力。翻译目录和本地化实现作为可选层接入同一个稳定入口。业务组件持有的入口引用在翻译层加载前后保持有效，组件无需为翻译可用性分别编写分支。

翻译脚本或目录加载失败时，页面以原文继续显示，Home 的状态读取与刷新、Watchboard 的表单与操作提交继续工作。翻译渲染抛出异常时，统一入口在该次显示调用中返回原文，并保留一次诊断提示；其余正常翻译继续可用。静态文字处理异常也不得阻断业务初始化。

页面启动恢复在外部脚本之前工作。其错误面板在显示时使用已可用的统一语言入口；文字层尚未加载时直接显示原始诊断，重试和恢复不依赖翻译资源。若翻译层在文档解析完成前恢复，已有面板随文档初始化刷新为所选语言，不另存一份语言偏好或启动词典。

降级沿用原有动态值转义和单次参数替换规则，不更改业务数据、权限、请求或事件处理。翻译不可用时不覆盖用户已经保存的语言偏好，不显示无法工作的公共语言选择器；显式设置语言仍须给出可读失败原因。账号偏好保存、业务请求和权限校验失败继续向其调用方传播，不纳入文字显示的异常处理范围。

验证需主动阻断翻译资源并执行页面核心操作，同时覆盖翻译延迟加载、损坏的翻译条目、动态内容转义和正常语言切换。

## 前后端请求与错误

浏览器公共 API 客户端和指令客户端在请求中携带当前界面语言。服务端优先采用受支持的 `X-Portal-Language` 请求头，其次采用浏览器的语言选择 Cookie，最后按 `Accept-Language` 的权重选择受支持的语言。没有语言信息的机器客户端保留英文诊断默认值。原版模式发送 `X-Portal-Language: original`，服务端原样透传错误响应，不将它标记为单一语言；日期格式化仍使用合法的语言标记。

HTTP 错误响应只本地化可读的 `error` 与 `message` 字段，包括指令错误对象中的同名文字。错误码、HTTP 状态、能否重试、提交状态、业务详情和权限判断保持原值。浏览器同样在错误显示边界翻译来自指令及请求的可读说明；后台日志、运行记录和领域服务中的诊断原文继续保存。

错误翻译按已登记原文或带参数的完整模板匹配。未知文字显示原文，不用通用错误覆盖具体原因。错误响应标记所用语言，并在缓存变化条件中包含语言相关请求信息。成功返回的业务正文保持原值。

## Family 操作文案

`Unfamilize` 的简体中文显示为“解除 family”。按钮、确认弹窗和进行中／完成提示统一使用该动词，并保留“保留成员”等已有说明。`Unfamilize Lineage` 按钮同样显示“解除 family”，其相邻说明继续表达整条 Lineage 的范围。英文与原版模式沿用原有文字；指令名称、行为和请求参数保持不变。

系统生成的新项目种子文件在创建时使用请求的模板语言，只转换产品标题与占位说明，项目 ID 和用户说明保持原文。既有文档不因语言切换重新生成。项目截止日期的英文相对天数区分一天与多天；Mailbox 数量、资源加载进度、设备观测前缀和后端固定状态在各自的展示入口本地化，动态用户值只插值一次。

## 维护边界

新增界面文字时在拥有该界面的渲染入口使用统一语言模块，将原文及两种语言加入翻译目录。新增指令和原语的帮助文字进入同一目录，但标识、参数与可执行配置不随语言改变。目录构建检查语言集合、参数一致性和浏览器产物一致性；验证同时覆盖语言持久化、失败恢复、动态结构、内容隔离和不同宽度下的操作入口。
