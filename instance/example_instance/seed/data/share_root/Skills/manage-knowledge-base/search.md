# 搜索与读取

## 确定项目

用户指定项目时，先用 HATG ISA `GetProject` 核对项目注册信息，使用返回的实际项目路径；不要把源站的 `${share_root}` 当作安装路径。

用户未指定项目时：

1. 根据当前会话、工作目录和项目摘要筛选候选项目。
2. 读取少量候选项目的 `summary.md`。
3. 能明确判断时直接搜索，并在回答中说明范围。
4. 多个项目同样可能相关且会改变答案时，再向用户确认。

不要根据显示名称猜测项目 ID 或路径。

## 搜索范围

1. 从用户问题提取主题、实体、接口、状态和时间线。
2. 搜索用户使用的词，也搜索同义词、上位概念、相关对象和相邻模块。
3. 先查最可能的类型对应目录，再补查一至三个近邻目录。`thinking`、`idea`、`insight`，以及 `decision`、`plan`、`todo` 等资源类型可能承载相邻语义。
4. 先用文件名、YAML 头部和全文搜索缩小范围，再完整读取最相关的条目。
5. 回答前复查核心定义、当前 Design 和更新的替代条目，避免把历史记录当成现行口径。

本地文件可见时优先使用 `rg` 定位。Portal 已附加资源引用时，使用 ResourceService 读取正文；只给出资源 ID 时，按 `${share_root}/Skills/tfi-unified-id/SKILL.md` 解析，不根据标题或路径猜测。

## 回答

- 结论只来自实际读取的知识库内容。
- 多项目结果要标明各自来源。
- 未命中时说明搜索过的项目、目录和关键词。
- 区分知识库事实、外部资料和自己的推断。
- 只读请求不得顺手修正文档。
