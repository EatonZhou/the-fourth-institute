# 使用示例

## 自动判断类型

> “把这段项目讨论整理一下，抽取可以归档的概念、想法、洞见或决策。”

> “从这段会议记录中提取值得归档的条目，并自动判断类型。”

## 明确指定类型

> “把这段内容按概念归档：Runtime Patch 是我们项目对运行时热修补机制的重新定义。”

> “归档想法：让规划 Agent 在生成计划前先读项目摘要。”

> “归档洞见：上下文切换往往比推理本身更容易拖慢多 Agent 系统。”

> “归档问题：为什么同一任务在部署运行域和操作运行域中需要不同调度策略？”

> “更新 Design：说明 Resident、Lineage 与 Workspace 当前如何分工和交互。”

> “归档思考：是否应该把 Agent 图的部分绑定延迟到运行时？这样虽然更灵活，但可能增加调度和观测复杂度。”

## 控制内容范围

> “把这段话整理成一个简洁的洞见，不要扩展影响和建议。”

> “把这段内容归档成想法，只介绍想法本身，不要扩展价值和风险。”

> “把这个问题整理成问题条目，必要时补一句背景，但不要编造解决标准。”

> “把这段连续思考整理成思考条目，保留思路，不要硬套结构。”

## 直接保存

> “提取这段笔记中值得归档的条目，并直接保存到 OSForAgent。”

> “把这项当前设计整理后保存到指定项目，保留相关来源。”
