**AI Society Is All You Need：从单个 Agent 到持续发展的科研社会**: Portal 是支持人与 AI 长期协作的软件。这里的 Agent 指能够根据目标推理、调用工具并完成工作的 AI 执行者。本文围绕自动科研（auto research）思考：**同样的智能能力，怎样组织才能发挥得更好？** 我们希望让不同问题得到持续探索，让局部发现相互启发，并让经验帮助后续研究，为 AI 之间、人与人之间、人与 AI 之间的协作建设共同环境。本文保留为设计哲学的探索，组织设想与效果判断仍有待检验。

## 模型外部的研究者还能创造什么

当训练更强基础模型所需的资金、算力和工程条件超出多数研究者的能力时，组织已有智能仍是一条研究路径。相同的个体能力，在不同的协作条件下可能产生不同结果。哪些信息能够流动，成员如何理解彼此，失败如何被发现，经验怎样留下，都值得研究。

多个 Agent 可以共同组织这些思考，一个能力足够强的 Agent 也可能在内部维持多条思路，分别保存材料、继续探索并交流结果。Agent Society 为这种多线探索、交流与积累提供了一种组织形式。我们关心这种组织能带来什么价值，而不预设成员越多就越有能力。

“AI Society Is All You Need”表达了我们的方向感：把能够持续工作的 Agent 社会作为一种值得探索的科研组织形式。标题中的强调是一项信念；模型能力、工具条件与实验质量仍然影响成果，组织带来的额外价值需要通过研究检验。

## 为什么选择 Agent Society

我们选择 Agent Society 作为 auto research 的组织基础，是希望**自动化“提出问题—分化探索—相互检验—重组发现—积累知识”的完整过程**。研究议程可以随探索变化：异常成为新问题，局部成果产生新联系，暂时搁置的方向也可能被新证据重新激活。

为此，我们希望 Society 保留**多个问题提出中心**，让成员发现不同的研究机会；保留**相对独立的探索历史**，给尚未成熟的想法发展空间；通过**选择性的交流与重组**产生新方法；并让**成果、失败和未解问题跨任务延续**。这些能力使研究有机会同时保持差异、积累知识和修正判断。

我们希望**不同思路有机会独立发展**。如果所有成员过早接受同一种解释，增加成员也可能只是重复同一种判断。不同的材料、假设、方法和探索经历，才有机会让一个成员发现另一个成员忽略的问题。分布式演化的类比也提供了一个直觉：不同分支尝试不同路径，某一路径失败时，其他路径仍可继续。交流应当帮助比较证据、修正错误，同时给尚未成熟的想法留下空间。

多中心也允许局部协调。团队可以由某个成员组织当前工作，也可以为共同目标形成高度整合的整体。**局部整合与社会中的多样性可以共存**，整合范围随工作需要变化。

## 研究内容与组织共同演化

**自组织演化是这一设想的核心：Agent Society 的产物可以包括新的知识、新的问题，以及适合继续研究这些问题的新组织。** 已有问题产生解释、证据和方案，形成内容生成；独立思考建立新的依赖、争议与合作，产生关系生成；这些关系进一步促成新分工、新成员和新研究线，也让旧结构调整或退出，带来组织生成。任务图、分工和交流关系，都可以在研究过程中被检验和修订。

例如，分别研究 A、B 的两个成员发现，它们共同依赖一个未验证的假设 C。于是，C 成为独立问题，吸引成员专门研究；其结果又改变 A、B 的方向和原有分工。研究内容与研究组织由此相互塑造，结构变化可以由局部发现和互动触发，无须预先写进一份完整计划：

**思考 → 新问题与新联系 → 组织重构 → 新的思考条件 → 新的思考。**

组织方式影响哪些思维片段有机会相遇，相遇产生的发现又改变组织方式。思维网因此既承载发现，也塑造未来发现的可能性。持续变化本身还不足以说明进步；我们希望实验、证据和成果参与选择，让有效结构延续、无效结构退出，同时为尚未成熟的方向保留探索空间。

## 个体如何由群体构成

Portal 当前用 Resident 表示能跨多次会话延续的 Agent 身份，用 Lineage 组织一组持续协作的 Resident。Resident 属于某个 Lineage，成员可以有不同来源，集合中的关系也可以超出从同一上下文分支而来的关系。

在本文的未来设想中，Resident 还可以承载另一种理解：它是在当前观察层级中，外部能够与之交互的一个个体。这个个体内部可以只有一个执行者，也可以存在多个协作者。

**Family 指通过信息同步与整合，让多个 Resident 对外表现为一个个体的组织方式。** 它描述成员形成整体的方式。Family 可以包含具有不同经历的成员；共同来源与对外形成整体分别回答不同的问题。

Lineage 让多个成员共同工作，Family 进一步探索共同理解与协调行动。理想中的整体能够承接外部目标、延续工作并给出协调后的回应。**对外形成整体，仍可在内部保留不同解释、独立探索和未解决的分歧。** 成员可以分别寻找材料、尝试方法和检查结果，需要整合到什么程度由当前工作决定。统一入口解决外部从哪里进入，持续的信息整合关系到这个整体如何理解和行动。

个体与群体的边界因而可以随观察层级变化：内部是多个成员的交流，外部则可能表现为一个持续协作的整体。哪些信息需要同步、分歧如何处理、对外回应怎样形成，是 Family 值得继续研究的问题。

## 同一种组织逻辑可以逐层重复

当 Family 的整合范围覆盖整个 Lineage 时，可以把这个 Lineage 对外呈现为上一层中的一个 Resident。它再与其他 Resident 组成新的 Lineage，继续按照需要开展协作与整合。

```text
多个 Resident 在一个 Lineage 中协作
                  ↓
Family 的同步与整合覆盖整个 Lineage
                  ↓
这个整体对外作为上一层的一个 Resident
                  ↓
与其他 Resident 组成新的 Lineage
                  ↓
按需要继续整合与组合
```

这里所说的“压成一个 Resident”，是让上层把内部协作当作一个参与者使用：向它表达目标、观察进展并接收结果。下层保留成员和工作关系，检查或调整工作时仍可查看内部结构。对外形成整体的具体身份与操作方式，留待后续设计确定。

由此可以用 `(Resident → Family → Lineage)^n → Whole Society` 概括这种递归设想。递归指同一种组织方式可以重复应用；`n` 表示根据需要形成的层数；Whole Society 指不同规模的个体与群体共同构成的协作社会。各层选择适合自身工作的整合程度，不预设固定层数，实际深度受任务、资源和协调成本影响。

Project 是 Portal 中保存项目目标、知识与工作材料的项目单位。从这套设想观察，它目前提供了一个相对固定的、更大范围的组织位置，可以类比为较死板的上一层 Lineage。未来递归结构所探索的额外能力，是让协作整体直接作为成员参加上一层协作；Project 的资料与管理职责可以继续单独理解。Family 和上述递归整合目前都属于待实现、待讨论的方向。

## 为跨个体协作建设共同环境

**好的组织，需要同时为专注和相遇创造条件。** 不必让每个成员随时理解全部研究。让各条研究线先围绕自己的问题深入，再把相关发现交给需要它们的人，有机会减少反复整理无关材料的负担。彼此联系紧密的问题需要及时交流，相对独立的探索可以晚一些汇合。

共同环境为能力互补提供交流与反馈的途径：让目标、证据和判断到达相关成员，决定成员能接触哪些材料、尝试哪些行动，以及怎样检验合作的价值。Portal 可以据此支持 AI 之间交换有来源的经验、人与人借助共同材料和记录协作，以及人与 AI 表达意图、理解反馈和调整工作关系。三种合作都涉及信息传递、分歧处理和成果接续，也各有表达习惯与参与方式。

**不同路线的局部成果，也可能组合成一条新路线。** 一条研究路线可能找到了好的问题描述，却没有找到解法；另一条路线可能发展出一种方法，却没有找到合适的用途。把两者联系起来，就可能形成原先任何一条路线都没有提出的方案。共同环境需要让这些成果能够被发现、理解和重新使用，并支持检验它们能否真正结合。

长期缺少交流也容易重复劳动。一个可探索的节奏是先独立形成判断，再比较证据、尝试重组，最后按工作需要形成整体回应。统一行动时仍保留疑问和反对依据，为后续修正留下材料。

## 让经验延续，让组织保留变化的空间

Portal 的 Fork 从已有上下文创建新的 Resident；上下文包括起步时可读取的讨论、材料与已有判断。新成员从共同起点出发，随后可以经历不同任务。本文借用“代际发展”描述经验的延续与分化，关注的是软件中的身份、记录和实践过程。

值得传递的经验包括有效方法、适用条件、失败线索与未解问题。团队暂停后，材料仍可能帮助其他团队，支持搁置问题的重新激活。这种可延续性，让社会的活力跨越单轮任务。

自组织演化也需要面对成本与失误：成员和层级增加可能提高沟通与检查成本，同源判断可能反复强化，统一回应可能遮住重要分歧。是否继续、暂停或改组，应结合证据与实际收益判断，并保留可复用经验。人可以参与研究方向、资源安排与成果验收，在授权范围内检查或暂停工作；具体参与方式可随协作实践发展。

## 怎样检验个体之上的智能

我们的研究假设是：**对于开放式、长期、研究议程持续演化的 auto research，能够保留差异、交换证据、积累经验并持续重组的 Agent Society，可能比单一持续轨迹更适合作为组织基础。** 最终应检验，它能否在可比的长期预算下，产生更多有价值、可复核、能够支撑后续探索的研究成果。

一个比较起点，是让单个强 Agent、固定分工的团队，以及能够整合、分化并递归组合的团队，完成同类连续科研任务。单 Agent 的比较对象也应保留有效的上下文管理与持久记忆能力。模型能力、工具条件、总运行预算与人工指导时间可以作为比较条件，同时记录通信和协调开销。

观察重点包括成果是否正确且可复查、新解释是否有价值、旧经验是否帮助新任务，以及分歧和组织变化是否带来实际改进。还应比较不同整合程度：对外作为一个个体后，协作是否更清楚、内部问题是否更难发现，增加层次是否足以抵偿成本。独立评阅与长期观察，有助于区分一次并行加速和持续积累的价值。

接下来值得继续讨论的问题是：

- Family 需要同步与整合哪些信息，才能形成持续、协调的对外行动？
- 一个 Lineage 何时适合对外作为 Resident，上层仍需要看见哪些内部信息？
- 递归整合怎样保留独立探索和经验分化，同时控制通信与协调成本？
- 人怎样参与不同层级的协作，并理解和调整这些层级之间的关系？
- 哪些新问题与联系值得触发组织变化，怎样兼顾证据选择与尚未成熟方向的探索空间？
- 在相同预算下，哪些结果能说明递归组织获得了单体或固定团队缺少的科研能力？

我们希望探索的智能社会，可以持续形成个体，让个体重新组合成群体，并在研究推进中调整自身组织。**让不同思路有机会深入，让有价值的发现有机会相遇，让研究成果反过来改善组织研究的方式。** 为这种跨个体、跨层级的协作建设环境，是模型外部研究者能够深入开展的一条研究路径。
