# Portal Workspace Surface 与 Document Session

Workspace Surface（文档工作区）是 Portal 中打开、阅读和编辑文件的通用界面层。Society 页面中个人 Workspace 的文件、Resident 的工作目录、Repo 与 Project 的文件、知识条目的正文都通过它显示。文件树列出可打开的文件，Preview 用一组文档标签页显示预览或编辑器；导航树与 Preview 可以放在独立面板中。用户可以同时打开多份文档，在预览和编辑之间切换，保存修改，固定或关闭标签页，并把选中的文字或代码行作为引用加入 Chat。

Document Session（文档会话）记录一份打开的文档当前处于什么状态：显示的是哪份内容、有没有进入编辑、草稿是什么、有没有未保存的修改、是否正在保存、有没有错误。每个标签页对应一个 Document Session。

本篇说明文档工作区的界面、Document Session 的规则、标签页与引用的接口，以及它们怎样作为 Workbench 面板接入页面。文件内容的格式识别和各种渲染器见 decision_61e50306cc79；资源详情页的地址与浏览器历史见 decision_864d4fe41934；Workbench 面板布局见 decision_538e155e1102；终端见 decision_f22e45dfd382。

## 基本概念

| 名称 | 含义 |
| --- | --- |
| 文件树（Explorer） | 按目录或业务层级列出可以打开的文件。 |
| 文档标签页 | 显示标题、当前标记、未保存标记、固定按钮和关闭按钮。每个标签页用一个稳定的键识别，对应一个 Document Session。 |
| 编辑器 | 编辑正文或代码的区域，代码使用 Monaco 编辑器。 |
| 预览 | 按文件类型显示 Markdown、图片、PDF、音视频和其他格式的区域。 |
| 工具栏 | 按当前文档显示返回、编辑、保存、刷新、下载、代码/可视化切换、撤销/重做和自动换行。 |
| 基线 | 最近一次从服务端读到或保存成功的内容。草稿与基线不同时，文档有未保存的修改（`dirty`）。 |
| 固定（pin） | 被固定的标签页不会被下一份打开的文档替换。 |
| 放弃确认 | 有未保存的修改时，关闭、切换或重新读取之前询问用户是否放弃修改。 |
| 选区引用 | 从选中的文字、代码行或图片区域生成的一条引用，可以加入 Chat 输入框。 |

## 设计点

### 布局

- **文件树和预览可以组合，也可以独立。** Society 页面的个人 Workspace 在左侧导航中，右侧 Preview 只挂载文档标签页与工具栏，不再挂载工作区树和两者之间的 splitter。共享 Preview 的 `surface.explorer: false` 表示文档独立布局，不生成隐藏的 Explorer 节点或折叠/拖动控件。需要组合布局的其他宿主仍使用两个分区；在组合布局中，两者的标题栏高度、背景、分隔线和折叠按钮大小相同；折叠按钮始终占据标题栏末端一个完整的方形区域，并带有 `aria-controls` 和 `aria-pressed`。文件数量这类信息放在标题和折叠按钮之间，不缩小按钮的点击区域。折叠任一分区只改变这个面板的布局，不影响打开的文档、当前标签页和文件树内容。
- **预览面板没有单独的标题行。** 文件名由当前标签页显示；文档显示成功后，工具栏末端显示当前文件的完整路径（悬停可以看到完整文字），双击这里复制路径。加载中和出错时，这里显示加载或错误信息；没有打开文档时不显示路径。各页面补充的操作放进文档工具栏或标签栏。
- **工具栏按面板宽度紧凑排列。** 编辑和可视两种模式的选中状态使用轻量样式；完整路径只占剩余空间，超长时省略。标准操作在最小 280 像素宽的面板中保持一行，页面补充操作放不下时自然换到下一行。

### 个人 Workspace 导航

- **每位用户拥有自己的多个工作区分组。** 导航栏的 Workspace 入口展示名称和文件夹树。分组保存名称及多个服务器绝对目录路径，通过 UI Association `lineage-workbench.workspaces` 按当前登录用户存储，每个分组使用一个独立键（decision_bd179998ba08）；刷新、重新登录和更换设备后可以恢复。这个个人分组不创建磁盘目录、不登记为 Workspace 资源，也不改变 Resident 的 Workspace Binding。
- **添加文件夹先检查目录与访问权限。** 使用现有文件链接接口的 metadata 请求确认路径存在且为目录，保存服务端规范化后的路径；记录一个路径不授予访问权，展开目录、预览和保存仍由对应文件服务检查当前用户权限。移除分组或目录只移除导航记录，磁盘文件和已经打开的 Preview 文档保持原样。
- **目录按用户展开动作读取。** 初始只显示添加的目录；展开时只请求该层直接子项，子目录继续展开才读取。完整列出子项，不按固定条数截断。请求去重，结果保存在当前面板内存中；刷新按钮重新读取分组与已展开目录。读取失败显示可重试的错误，不把权限错误当成空目录。不进行后台轮询。个人 Workspace 分组不会因切换 Resident 被修改。
- **紧凑文件树沿用共享组件。** 工作区是细分组栏，文件与目录沿用 PortalFileTree，添加和移除采用共享图标按钮、提示和对话框。点击文件交给已有 Preview 打开流程，沿用文档标签页、草稿保护和异步结果校验。折叠和选中是面板内的显示状态，不保存文件内容。

### 当前对话的 Workspace

- **Workspace 导航自动展示当前 Chat Resident 绑定的工作区。** 绑定目录列在个人分组之前，直接采用 Resident 工作区服务返回的身份、路径、名称和第一层目录内容，默认展开；更深的目录仍按用户操作读取。切换 Resident 时立即移除上一位 Resident 未锁定的绑定展示，只接受当前目标的读取结果。没有绑定或读取失败时明确显示状态。
- **自动展示与个人收藏分开管理。** 自动展示不写入用户的 UI Association，也不改变 Resident Binding；绑定条目不提供个人分组的删除或添加目录按钮。个人工作区和已打开的 Preview 文档保持原样。Workspace 的刷新入口同时重读当前 Resident 的绑定和个人分组，复用既有服务，不增加后台轮询。

- **目录可以锁定在导航中。** Resident 绑定目录、直接打开的 Workspace 及已保留目录，在工作区标题栏的最右侧提供始终可见的锁定按钮；收起工作区时仍可操作，点击锁定不改变展开状态，内部目录行不重复提供该按钮。个人分组可包含多个目录，各目录仍在自己的目录行独立锁定。按钮说明保留与解除保留的效果。锁定按目录绝对路径识别，通过同一用户的 UI Association 保存独立的 `locked-directory` 记录，内容仅含名称与路径。锁定后切换 Resident、刷新和重新登录仍保留该目录；当前绑定或个人分组已经展示同一路径时不另外生成重复条目。解锁只取消独立保留，当前绑定或个人分组中的目录继续显示，已打开的 Preview 文档不受影响。保存或删除锁定记录失败时保留先前状态并显示错误。锁定不改变 Resident Binding、不修改磁盘文件，也不授予文件访问权限。

### 打开与切换文档

- **打开同一份文档只激活原来的标签页。** 需要重新读取时显式调用 `reload`，重新读取同样经过放弃确认。
- **通过文件右键菜单选择“在新标签页打开”时保留当前文档。** 当前文档与新文档都固定，当前草稿不触发放弃确认；点击标签即可切换。目标已打开时激活并固定已有标签，不生成同一文档的副本。菜单与下载归 decision_61e50306cc79 管理。
- **普通点击时，没有固定的当前标签页会被下一份文档替换。** 这样连续浏览文件时不会堆积标签页；固定当前标签页后，新打开的文档使用新的标签页，并同样处于固定状态。
- **替换或重新读取有未保存修改的文档前，先询问是否放弃。** 用户选择留下时，目标文档、草稿、标签页和地址都保持原样。固定的标签页保留自己的草稿，打开其他文档不会丢弃它。
- **快速连续打开时，只显示最后打开的文档。** 较早发出的读取晚到时被丢弃；读取失败时，错误显示在这个标签页中。
- **关闭标签页后选择相邻的标签页。** 关闭当前标签页时优先选右边，没有再选左边；关闭最后一个时通知页面（`onEmpty`）。关闭有未保存修改的标签页前，先由它自己的 Document Session 询问；用户选择留下时，标签页顺序和当前文档不变。
- **渲染失败只影响预览区域。** 某种格式渲染出错时，只有预览区域显示错误，标签页和草稿不受影响。

### 预览面板的“返回上一个文件”

- **预览面板记住最近打开过的文件，可以逐个返回。** 新文件显示成功后，才把此前的文件加入返回列表；加载失败、刷新当前文件、连续打开同一个文件和返回操作本身都不加入。返回列表默认最多 32 项（面板可以配置，最多 256 项）。
- **返回成功后才移除这一项。** 返回的目标加载失败时，这一项保留，用户可以重试。返回按钮在标签栏中紧挨固定按钮左侧；没有可返回的文件或正在返回时禁用，按钮提示显示将要返回的文件的标题或路径。返回只在面板内切换文件，不改变浏览器地址和浏览器历史。

### 编辑与保存

- **有内容、允许编辑的文档才能进入编辑。** 是否允许编辑由读取结果中的能力（`canEdit`）决定，工具栏不根据文件扩展名推断能否写入。进入编辑后，草稿与基线不同就标记为未保存。
- **保存成功后仍停留在编辑状态。** 基线更新为保存的内容，未保存标记清除。保存失败时保留编辑状态、草稿和未保存标记，并显示错误。
- **保存前再次检查权限。** 保存时重新确认文档仍然允许编辑、正在编辑、有未保存的修改、没有其他保存在进行，并且提供了保存方法；任一条件不满足时拒绝保存，草稿保留。
- **保存中不能取消编辑。** 取消编辑时，有未保存的修改先询问是否放弃。

### 编辑器状态栏

- **文件编辑区底部始终显示当前草稿的统计与位置。** 状态栏展示字数、字符数、总行数、光标行与列、文件语言和 LF/CRLF 换行格式；修改、撤销和重做后更新，不等待保存。
- **字数按中文逐字、英文按词统计。** 汉字每字计一，其余连续字母或数字计一个词，词内撇号保留；标点和空白不计入字数。字符数按 Unicode 码点计数，包含标点、空格、制表符及换行；单个增补字符（如单码点 emoji）计一，CRLF 包含两个字符。
- **总行数以文件实际换行为准。** 自动换行产生的视觉行不增加总行数，空文档为一行；光标行与列沿用编辑器的一起始位置。
- **选中文字后显示选中字符数。** 空白选区也计数，多选区相加；取消选择后隐藏选区统计。
- **点击光标行与列可以跳转到指定行。** 操作使用编辑器已有的行定位输入框，保留焦点和键盘操作。
- **窄面板中的状态项目自动换行。** 状态栏留在编辑区底部，不覆盖正文、标签页或保存工具栏。退出编辑、关闭或切换文档时清理旧文档的统计与订阅。

共享代码编辑器 `PortalCodeEditor` 负责从当前模型与选区计算状态，Preview 在挂载编辑器时启用状态栏。全文统计只在内容变化时重算；光标移动复用已有统计，各类更新合并到下一次绘制。统计只保存在当前编辑器内存中，不新增请求或持久状态。

### 刷新页面后恢复标签页

- **预览面板在刷新页面后恢复打开的标签页。** 面板保存标签页顺序、当前标签页、固定状态、返回列表，以及每份文档的定位信息（资源地址、路径、链接、身份和行列位置）。文档内容、草稿、`data:` 地址和加载函数都不保存；恢复时由页面把定位信息重新转换成读取请求。
- **一项恢复失败不影响其他项。** 某个文档无法重新定位或读取时，移除这个标签页及其保存记录，继续恢复其余标签页。恢复期间用户主动打开了其他文档时，停止恢复，以用户的选择为准。页面代码晚于面板初始化时，面板先暂存保存的记录，等标签页控制器创建后再恢复。
- **没有可以恢复的标签页时，Resident 工作目录自动预览第一个普通文件。** 目录、符号链接和操作系统生成的文件（以 `._` 开头的文件、`.DS_Store`、`.localized`、`Thumbs.db`、`desktop.ini`）不参与自动预览；没有合适的文件时预览保持空白。

## Document Session

`PortalDocumentSession.create(options)` 创建一个 Document Session。初始状态为 `status="empty"`、`payload=null`、`editing=false`、`dirty=false`、`saving=false`。每次状态变化都通知订阅者，并带上变化原因。

状态快照包含：`status`（`empty`、`loading`、`ready`、`editing`、`saving` 或 `error`）、`payload`（当前内容）、`requestId` 与 `requestKey`（当前读取的编号和键）、`editing`、`draft`、`dirty`、`saving`、`error` 和 `readError`（保留旧内容时最近一次刷新读取失败的原因）。`actionState()` 由状态计算工具栏可以使用哪些操作：`editable`、`canEdit`、`canSave` 和 `canOpen`。

| 方法 | 作用 |
| --- | --- |
| `snapshot()` / `subscribe(listener)` | 读取状态；订阅状态变化，返回取消订阅的函数。 |
| `open(request)` | 经过放弃确认后读取新的目标。 |
| `present(payload, meta)` | 用已有内容建立新的基线；传入 `null` 时回到空白。 |
| `show(payload)` | 按调用方给出的状态、内容和错误显示。 |
| `setReadError(error)` | 记录刷新读取失败，保留当前正文、编辑状态与未保存草稿，并通知订阅者。 |
| `beginEdit()` | 允许编辑时进入编辑。 |
| `updateDraft(value)` | 只在编辑中、没有保存在进行时更新草稿。 |
| `cancelEdit()` | 有未保存的修改时先确认，再退出编辑。 |
| `save(request)` | 保存当前草稿。 |
| `guardDiscard()` | 有未保存的修改时询问是否放弃；调用方没有提供 `confirmDiscard` 时使用 Portal 共享的危险确认对话框。 |
| `invalidate()` | 作废正在进行的读取和保存，可以中止的读取立即中止。 |
| `destroy()` | 作废全部正在进行的工作并结束订阅，可以重复调用。 |
| `actionState()` | 返回工具栏可用的操作。 |

**读取。** `open(request)` 先询问是否放弃。这次确认只针对发起操作时的那份文档和草稿：等待确认期间用户切换了文档、继续修改或开始保存，原来的确认失效，不会丢弃新的内容。用户拒绝或确认失效时不切换；确认后进入 `loading`，可以用 `loadingPayload` 显示切换过程中的内容。`request.load` 收到 `AbortSignal`、`requestId` 和 `requestKey`；已经过时的结果和被中止的读取返回 `stale: true`，不显示。读取返回 `null` 且调用方不允许空白时进入空白状态，读取抛出的错误显示为错误文字。

**刷新失败。** 文件被删除、失去访问权限或暂时读取失败时，旧内容可以保留，但面板必须持续显示读取失败原因并明确标示“当前显示内容尚未更新”。这个提示属于对应文档的 Session；切换到其他标签页不显示它，切回时仍可见。重新读取成功后清除提示，原有刷新入口仍可重试。读取期间产生的新草稿和未保存标记继续保留；失败回执不能覆盖已切换的文档或较新的读取结果。

**编辑。** 调用方设置 `continuousEdit` 时，文档显示后直接进入编辑，草稿取自内容；否则由 `beginEdit` 进入编辑。

**保存。** `request.save` 收到当前内容、草稿和保存编号 `saveId`。较早的保存结果晚到时被丢弃；保存成功后返回的部分字段与原内容合并，没有返回 `content` 时以提交的草稿作为新内容。

读取和保存各有一个作废计数。`invalidate()`、打开新目标和 `destroy()` 都会提高计数，使旧结果失效，所以读取、切换和保存不依赖网络响应的先后。Document Session 销毁后不再接受打开、编辑、显示和订阅，此前发出的确认也不能重新激活它。

## 标签页、编辑工具与选区引用

`createDocumentTabsController(options)` 管理一组标签页：每份文档、标签页顺序、当前标签页、固定状态和各自的 Document Session。`open` 接受 `mode: "new-tab"` 表示显式保留文档；其他打开请求沿用复用规则，恢复时按记录中的固定状态还原。它提供 `open`、`activate`、`active`、`isActive`、`get`、`close`、`togglePin`、`render`、`snapshot`、`persistenceSnapshot`、`restorePersistence` 和 `destroy`。页面提供 `serializeDocument` 把文档转换为可以保存的定位信息，提供 `restoreDocument` 把定位信息转换回读取请求。`togglePin` 同步按钮的 `aria-pressed`；控制器销毁时销毁全部 Document Session。

`createDocumentEditorTools` 为编辑器提供分组的撤销/重做和自动换行偏好。使用 Monaco 编辑器时，精确的行选择和自动换行交给 Monaco 管理。`renderDocumentTabs`、`renderExplorer`、`entryVisible` 和 `parentPaths` 是只负责界面、不读取数据的辅助函数。

**选区引用**：用户在预览或代码中选中内容后可以加入 Chat。选中的文字会去掉 Markdown 标记，生成可以搜索的文本；代码引用保存文件路径和精确的行号范围；使用 Monaco 时由 Monaco 提供选区；选中的图片区域作为 Chat 附件加入输入框。引用只说明选中了什么，文件本身仍由原来的服务管理。

编辑或可视模式中有选区时，在选区旁显示“添加到当前聊天”按钮；文档工具栏不另放添加入口。没有选区时不把整份文档作为引用加入。

## 作为 Workbench 面板接入

文档工作区注册三种 Workbench 面板（面板包版本 1，状态保存格式版本 1）：

| 面板 | 最小尺寸 | 接收的上下文 | 面板命令 |
| --- | --- | --- | --- |
| `authored`（编辑器） | 360×180 | `documentTarget`、`commandContext` | — |
| `preview`（预览） | 280×180 | `documentTarget`、`commandContext` | `back`（返回上一个预览文件）、`reload`（重新加载） |
| `terminal`（终端） | 280×160 | `workspace`、`commandContext` | `interrupt`（中断任务）、`restart`（新建 Shell） |

三种面板都可以在一个页面中打开多个，每个面板只从自己的绑定和保存的状态中恢复，不与其他面板共享正文、草稿、终端或选区。预览面板保存的状态包含标签页控制器输出的记录和面板自己的返回列表，只有定位信息。

Workbench 按面板包的约定管理面板：创建后依次调用 `connect`、`restore`、`setContext`；面板进入或离开可见区域时调用 `show`、`hide`；关闭时调用 `disconnect`、`destroy`。面板没有实现某个可选方法时，Workbench 继续完成布局。`destroy` 释放预览、选区控制器、标签页、Document Session、工具栏和面板的页面元素。

## 各部分的职责与故障处理

| 部分 | 负责 |
| --- | --- |
| 文档工作区 | 标签页、当前文档、预览面板的返回列表、Document Session、工具栏和选区。 |
| 页面提供的读取与保存方法，以及对应的服务 | 读取内容、保存权限和版本检查。 |
| 预览渲染器 | 各种格式的显示（decision_61e50306cc79）。 |
| 资源详情页 | 页面地址与浏览器历史（decision_864d4fe41934）。 |
| Workbench | 面板布局。 |

页面的读取与保存方法把 HTTP 409、403、404 和网络错误转换为这个标签页的冲突、无权限、已删除或可以重试的状态。保存失败不丢草稿，较早的响应不覆盖新的标签页，一个面板的错误只留在这个面板中。支持新格式时扩展预览渲染器；新的保存方式由对应领域的服务提供；改变页面地址或浏览器历史的行为由资源详情页负责。
