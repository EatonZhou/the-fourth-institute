# 组织更新中的局部学习与记忆继承

2026-10-16，局部学习方法研究。对应研究方案 `plan_13d78f0ae847`。

本轮实现了一个可微的局部线索学习模型：每处身体密度保存两种线索的伤害预测，新生密度从半径 1 的邻域继承预测状态。实验发现，在这一增强的 Orbium 模型中，**组织更新能迅速抹去没有内在衰减的记忆；初始等量记忆的长期影响取决于它位于身体的前部还是后部。** 保留前半身的已学记忆即可恢复几乎全部线索区分，保留后半身的同等记忆则逐渐失效。

这是一个已实现、已运行的候选学习机制。局部预测更新和防御读出由研究者设计，本轮没有训练外层参数。新的研究线索是记忆继承、组织更新和空间位置之间的定量关系；其跨形态适用性与完整学术新意仍需继续研究。

后续已把事后记忆擦除推进为**真实局部线索经历**：相同密度加权剂量施加于前部或后部，前部经历形成持久预测，后部经历主要留下短暂变化；同样多的反转信息能否改写旧预测，也取决于它出现的位置。详见下文的交叉反转实验。

## 主要结果

首轮在 64×64 周期网格上使用同一 Orbium 轨道的 4 个相位（第 500、537、574、611 步）。每个相位复制两条经历：相同伤害时序，交换线索 A/B 的身份。初始预测均为 0.5，因此对称学习使两条经历的身体逐位相同，预测状态按线索互换。四种继承方式都实际验证了身体最大差值为 0。

训练共 288 步：12 次刺激，每次 4 步、周期 24 步，伤害与安全交替；每种线索各出现 6 次。最后一次刺激后还有 20 步无刺激。表中休息从训练结束计时。线索、伤害和时间表属于外部环境，模型不能读取历史类别或全局计时。

| 继承方式 | 训练结束的线索区分 | 休息 40 步 | 休息 360 步 | 360 步后的匹配环境成本 |
| --- | ---: | ---: | ---: | ---: |
| 新生密度回到中性值，β=0 | 0.004763 | 0 | 0 | 0.395833 |
| 新生密度继承一半，β=0.5 | 0.014166 | 1.01×10⁻⁹ | 0 | 0.395833 |
| 新生密度完整继承，β=1 | 0.979767 | 0.979767 | 0.979767 | 0.291709 |
| 固定格点保留，格点灭活后清除 | 0.021848 | 0 | 0 | 0.395833 |

线索区分是身体密度加权的 `|w_A-w_B|`。成本是两个等概率情境（A 有害、B 安全，或其互换）下、反馈到来前决定的即时防御负担，单位由下文公式定义。β=1 比清空记忆降低该成本约 **26.3%**。清空同一身体的记忆后成本变为 0.395833；交换两种线索的记忆后成本变为 0.699946。所有 cue×toxin 组合均保存，避免只保留匹配环境中的有利结果。

首轮还实际运行了 4 步探测加 40 步恢复，并为每条探测复制无刺激分支。所有探测末态质量大于 71.40；这只是 44 步的短窗口，质量接近正常不能证明没有迟发损伤。图 D 使用即时成本；成本改善不能解释为已经证明存活优势。

### 延长观察后的命运与个体曲线

针对身体基线组发现的近正常质量下迟发消亡，直接从首轮保存状态延长观察到探测开始后 **1024 步**，没有重新训练，也没有筛选幸存者。保留四种继承方式、四个休息时长、四个相位、两种线索经历、三种记忆干预及全部 cue×toxin 组合，共 **1536 条探测分支和 128 条无探测分支**。这些是同一 Orbium 的条件分支，不能作为 1664 个独立样本。无线索时内部记忆不影响身体，因此同一起始身体的清空、交换与完整记忆干预共用一个与各自无探测演化严格等价的对照。

全部分支完成窗口内观察；探测与无探测分支均未灭亡（数值判据为总质量 ≤10⁻¹²）。前 44 步末态质量与原实验逐条复现，最大误差为 0。全时段最低质量为 70.9993，1024 步末态质量范围为 71.3290–71.8244；探测相对自身无探测对照的质量差分，按初始质量归一化后的全条件最大绝对值为 0.613%。这些数值描述本次有限窗口，不构成通用健康阈值，也不支持存活优势。

末态质量差分还依赖观察时刻：完整继承、休息 360 步、经历 0 的匹配危险线索探测，在第 44 步四个相位的质量差分都为负，第 1024 步其中三个变为正。因此不能用某个末态质量差分的符号代替学习收益。以下图逐条绘制四个相位，没有把振荡平均成一条平滑曲线；本次没有对长尾做运动相位匹配，不能仅凭这张图认定响应增益发生改变。

## 固定规则、可变状态与局部继承

`A[y,x]` 是身体密度，`w[cue,y,x]` 是两种线索的局部伤害预测。学习率 α、继承率 β、内在衰减 δ、身体核和增长规则在个体经历中固定。`w` 是内部状态；个体运行中没有外部优化器修改规则，也没有跨代遗传过程。

当前线索 `c` 是两个通道的 one-hot 或全零场，伤害 `h∈[0,1]` 是当地外部场。先读出旧状态，再更新记忆：

```
d = clip(sum_j c_j w_j / (2κ), 0, 1)
L = h(1-d) + κd²
A' = OrbiumStep(A, intensity = b L)
w_learn = 0.5 + (1-δ) [w + α c (h-w) - 0.5]
```

使用 α=0.15、κ=0.6、b=0.03、δ=0。`d` 不读取当前伤害；成本项包含当前伤害，是环境施加的身体后果。危险线索使当地预测增加，安全线索使其降低，无线索时不写入。防御成本通过共享仿真器的 `-dt * intensity * A` 耦合到身体增长。`simulation` 是身体更新的唯一实现，本模块不复制 Orbium 核或增长函数。

普通 Lenia 不守恒，也没有物质身份。本方法明确选择一个继承约定：当前与下一步密度的较小值视为保留部分，正密度增量视为新生部分。该约定不声称恢复了真实物质流。

```
r = min(A, A')
g = max(A'-A, 0)
donor = K₁*(A w_learn) / (K₁*A)
w' = [r w_learn + g (0.5 + β(donor-0.5))] / A'
```

`K₁` 是包含中心的 3×3 周期平均核。没有供体时使用中性值 0.5；死亡格点清为 0.5；计算中的活体阈值为 10⁻¹²。保留密度不发生额外扩散，新生密度才复制邻域状态。模型只使用局部场和局部邻域，不读取质心、运动方向或实验类别。`site` 对照使连续存活格点保持自己的状态，新占据格点从 0.5 开始。

## 复制路径解释遗忘速度

第二轮使所有 β 共用完全相同的无刺激身体轨迹，从全身均匀记忆开始，观察 480 步。完整继承保持均匀记忆；只要 β<1，复制中的微小损耗便随组织更新积累。

| β | 记忆减半所需步数 | 480 步后剩余比例（约） |
| ---: | ---: | ---: |
| 0 | 6 | 0 |
| 0.5 | 9 | 0 |
| 0.9 | 21 | 浮点精度附近 |
| 0.95 | 31 | 8.30×10⁻⁸ |
| 0.98 | 62 | 0.001595 |
| 0.99 | 112 | 0.040459 |
| 0.995 | 214 | 0.201800 |
| 0.999 | >480 | 0.726455 |
| 1 | >480 | 1 |

把身体冻结为 `A'=A`，同一继承操作连续执行 480 次，全部 β 的记忆保持误差为 0。因此本轮遗忘来自身体更新与复制约定的组合。

记忆可以沿保留路径继续存在，也可以沿新生密度的复制路径传播。定义 `D` 为该局部复制路径累计经过新生复制的平均次数，初始为零：

```
D' = [r D + g (1 + K₁*(A D)/(K₁*A))] / A'
```

在每次出生均有活体供体的轨迹中，均匀记忆的保留率可解释为 `R(β)=E[βᴺ]`，`N` 是复制路径中的复制次数。因此 `∂R/∂β|β=1 = E[N] = density_weighted_mean(D)`。这是给定继承算子的代数性质；无需将其归因于生物学谱系。局部 `D` 递推与 autograd 的敏感度在单元测试中一致。

本次 480 步的平均复制深度为 **319.450**，累计新生密度除以初始身体质量为 **49.731**，比值约 **6.42**。两个量的差别来自复制来源对后续身体的贡献不均匀。用整体新增密度直接估计记忆损耗会遗漏这种贡献差异。β=0.999999 的单边差分也验证了敏感度，最大相对误差 1.59×10⁻⁴，与有限差分截断量级一致。

## 等量记忆的空间干预

第三轮从首轮完整继承模型已经学到的状态出发。把身体按运动方向切成各占一半质量的前、后区域；边界格点使用分数掩码，使质量恰好各半。运动方向只用于构造实验干预，随后局部规则不能读取它。对 4 个相位再分别旋转 0、90、180、270 度，全部干预共用同一身体轨迹。

| 干预 | 初始线索区分 | 360 步后线索区分 | 360 步后即时成本 |
| --- | ---: | ---: | ---: |
| 全部记忆保留 | 0.979767 | 0.979767 | 0.291709 |
| 只保留前半身记忆 | 0.489884 | 0.979767 | 0.291709 |
| 只保留后半身记忆 | 0.489884 | 约 10⁻¹² | 0.395833 |
| 全身记忆强度减半 | 0.489884 | 0.489884 | 0.318773 |
| 全部保留，另加 δ=0.002 内在衰减 | 0.979767 | 0.476560 | 0.320207 |

前后半身初始携带同等的密度加权记忆，未来影响却不同；均匀减半对照保持中间值。复制使前部经验对未来身体的影响扩大。旋转条件间线索区分的最大偏差为 2.66×10⁻¹⁵，没有固定世界方向造成的效果。

完整继承允许把显式遗忘与组织更新分开控制。对于初始均匀记忆，δ=0.002 的实测区分等于无衰减区分乘以 `0.998^t`，最大误差 1.55×10⁻¹⁵。

## 等量真实局部经历与交叉反转

从首轮保存的四个未经训练的相位身体续接；未重跑原实验。每次训练仍为 12 次刺激、每次 4 步、周期 24 步，随后休息 120 步。首次训练 A 有害、B 安全；反转训练交换伤害映射。学习规则及 α=0.15、β=1、δ=0 在全过程固定。

外部实验器将线索投向前部、后部或全身分散区域；规则只看到本地线索与伤害，不接收区域身份、质心、运动方向或历史标签。前后方向由训练前 20 步无刺激运动确定，此后固定；局部区域随身体质心移动。逐步用 `sum(A*c)` 匹配剂量：同相位各条件每次刺激的目标为当时最小身体质量的一半。局部区域从对应边缘填充，边界格点取分数强度；全身分散条件的线索强度约为 0.5。伤害是所有条件共有的全局 0/1 场。全身分散控制同时改变刺激集中程度，因此前后位置效应的主要比较是前部与后部。

复用 `exposure_masks` 时需区分等剂量实验与固定外部接触：当前函数按各身体的质心和同组最小质量重新布置线索；若一枝消亡，同组后续剂量全部归零。因此在防御策略的损伤/消亡校准中，如需各策略面对同一外部接触场，应从预定或共同参考身体轨迹生成掩膜再共用，避免损伤通过剂量匹配改变其它分支的环境。上述已完成的局部经历实验没有消亡分支，其结论限于这里定义的等剂量干预。

设置两种身体耦合：`common` 使用 b=0，使所有线索经历共用完全相同的身体轨迹；`coupled` 使用原来的 b=0.03，允许防御成本作用于身体。共同身体条件全程逐位差值为 0；单次积分剂量误差最大 2.84×10⁻¹⁴，累计剂量的条件间差异最大 4.55×10⁻¹³。实际 20 步位移与预设方向的最小余弦为 0.999926，所以前后区域未因转向交换。

首次训练及休息结束后，身体密度加权的有符号预测差 `w_A-w_B` 为：

| 线索位置 | 共同身体：训练结束 | 共同身体：休息 120 步 | 带身体反馈：休息 120 步 |
| --- | ---: | ---: | ---: |
| 前部 | 0.979736 | 0.979767 | 0.979767 |
| 后部 | 0.000906 | 2.66×10⁻¹² | 2.40×10⁻¹² |
| 全身分散 | 0.846042 | 0.846042 | 0.845959 |

后部线索在刺激时能改变预测，但变化在刺激间迅速消失，重复刺激未积累成持久预测。前部半身的最终区分接近全身全强度线索的标量更新值 `1-0.85^24=0.979767`；全身半强度线索对应 `1-0.925^24=0.846042`。这是实测结果与简单更新式的事后比较，与此前前部复制来源占优的结果相符，不独立证明某条唯一复制谱系。

随后把每个已训练状态复制到三种反转线索位置，并分别保留或清空旧记忆，形成完整的 `3 种原位置 × 3 种新位置 × 2 种记忆干预`。各相位的这些分支继续匹配绝对线索剂量。以下为共同身体条件、保留旧记忆、反转训练并休息后，在新映射下的预反馈即时成本：

| 原学习位置 → 反转位置 | 前部 | 后部 | 全身分散 |
| --- | ---: | ---: | ---: |
| 前部 | 0.291834 | **0.699946** | 0.301344 |
| 后部 | 0.291709 | 0.395833 | 0.294136 |
| 全身分散 | 0.291812 | **0.646653** | 0.300081 |

中性记忆成本为 0.395833。原先在前部学习后，改在前部接受反转信息，预测差转为 −0.959944；改在后部接受同量反转信息，旧预测差仍为 +0.979767。清空旧记忆后，在后部重新训练的预测差接近零，而非形成持久的负预测差。由此可以分开两件事：旧预测确实导致新环境下的高成本；后部新信息也确实难以留存，清空旧预测并不能恢复后部的持久学习。b=0.03 的交叉矩阵保留同样的前后差异。

## 配对状态接口、积分器对照与有代价的决策

本轮按主理人的任务复用上述身体和慢状态，不另造模型。环境与后果使用环境组的[局部适应设定](../environment_evolution/LOCAL_ADAPTATION.md)：κ=0.6、b=0.03、可靠性参数 0.8，即稳定映射中两种线索的伤害概率分别为 0.9 与 0.1。每次事件只有首步呈现线索和伤害，随后 7 步无刺激。

`LocalLearner` 的原更新 **本来就是按线索分别更新的单时间尺度指数积分器**：`w_j ← w_j + α c_j (y−w_j)`。因此不能将其称为超越积分器的新关联学习算法。[controls.py](controls.py) 增加下列对照，全部共用身体引擎、成本、防御读出及 β=1 的组织复制：

| 条件 | 积分对象 | 更新率与读出 |
| --- | --- | --- |
| frozen | 无更新，中性预测 0.5 | α=0 |
| pooled_single | 不区分线索，出现任一线索时积分局部伤害 | α=0.15 |
| pooled_dual | 同上，两种时间尺度 | α=0.03、0.5，固定等权平均 |
| paired_single | 对当前线索单独积分局部伤害，即原模型 | α=0.15 |
| paired_dual | 每种线索各有两种时间尺度 | α=0.03、0.5，固定等权平均 |

积分器不在无刺激期把零输入误当成一次“安全事件”。双尺度参数和权重没有按本轮结果调优，各条件的有效采样次数和更新率不同；比较不能解释为某种时间尺度已达到最优。

感觉输入是相互独立的可见线索场 `cue[B,2,H,W]` 和局部伤害暴露场 `toxin[B,H,W]`，可按空间广播。后者表示防御之前的外部暴露，不是由模型反推出的潜在损伤。规则先由旧状态读出防御，再用本次观察更新；环境隐藏映射、伤害概率、世界编号、训练阶段均不进入规则。分开的感觉通道是设计假设，当前不研究如何从身体动力学中涌现这种感觉能力。

状态干预接口保留受体身体，只操作局部记忆；可传入 [0,1] 空间掩膜选择区域：

```python
from local_learning.controls import make_learner, intervene_state

learner = make_learner('paired_single')
state = learner.initial(body)
state, cost, defense = learner.step(state, cue, observed_toxin)
retained = intervene_state(state, 'retain')
erased = intervene_state(state, 'erase')
transplanted = intervene_state(state, 'transplant', donor=observed_donor)
```

供体必须具有相同通道含义和空间坐标系；接口不自动配准任意身体。本轮供体来自实际经历，没有脚本赋值“已学会”：同一随机伤害序列分别搭配原线索和交换后的可见线索，两个供体各自通过固定规则更新。两条经历只交换线索身份，身体后果逐步相同，因而能在相同空间坐标直接移植。

小案例从已保存的两个未训练 Orbium 相位开始，4 条独立随机经历、每条 64 次事件，休息 40 步后探测。每个原线索受体产生保留、擦除、真实相反经历供体移植三个分支；每个分支又独立运行 `两种线索 × 有/无伤害` 及无刺激 sham，共 600 条后续。所有探测只持续一步，探测时关闭新状态写入，随后无刺激至第 1024 步。线索但无伤害的分支仍承担防御成本，无刺激 sham 则同时去掉线索和伤害，两者含义不同。

固定探测状态后，将四种线索/伤害结果按环境概率积分，分别计算原映射和立即反转映射的期望成本；环境概率只用于事后分析。这个分支实验隔离已学状态的作用；持续反转后的重新学习由上一节和环境组已有实验承担，不重复扫描。

## 用各算子的伴随检验复制约定

已完成有限 CPU 敏感性实验，复用主理人的 [memory_influence.py](../analysis/memory_influence.py) 中质量预算和集中度定义。从首轮 `growth_1_trained.npz` 的四个相位身体开始，共用同一条无刺激 360 步身体路径；新实验的末态身体及原算子的全部伴随场，与主理人的 `8fb3c383-7074-4fd4-979d-e496c62f9825` 结果逐位相同。这里固定身体路径，不把改动后的状态耦合回身体。

只取六项条件：原 3×3 均匀供体核、1×1 自身供体核、5×5 均匀核；在原 3×3 上分别加入 λ=0.25、1 的保留组织交换；另保留原 β=0.98 衰减对照。除最后一项外 β=1，未做核尺度×交换×β 的全组合。代码在 [copy_operators.py](copy_operators.py)，原基线直接调用既有 `inherit`，不修改既有学习模型默认参数。

交换有明确的质量通量定义。对一步身体 A→B，保留密度 `r=min(A,B)`，新增密度 `g=max(B−A,0)`，四邻域对称通量为：

```text
c_ij = (λ/4) min(r_i, r_j)
(F_r z)_i = r_i z_i + Σ邻居j c_ij (z_j − z_i)
```

全部通量同时用交换前状态计算，周期边界。在 λ∈[0,1] 时，交换后的保留组织浓度是邻居浓度的凸组合；由于 `c_ij=c_ji`，`Σ F_r z = Σ r z`，因此**仅交换阶段守恒保留密度加权记忆**。新增组织仍从旧身体、交换前状态取样；整个身体更新包含组织消失和复制，不因此成为全局记忆守恒过程。这与不加密度权重的局部平均不同。

对中心化状态，前向和伴随分别为：

```text
Tz = [F_r z + β g K(Az)/K(A)] / B
T* v = F_r s + β A Kᵀ[g s/K(A)],  s=1[B>eps] v/B
```

空供体池不传递状态，空目标位置恢复中性值。`F_r` 在欧氏内积下对称；浓度映射 `r⁻¹ F_r` 本身通常不对称。每种新算子独立反传至初态，未沿用原权重。主实验使用对称方形核；实现支持非对称核并在伴随中翻转两个空间轴，另以非对称核、死亡/空供体位置和随机状态核对前向—伴随对偶关系。

## 已有工作与研究边界

- [Differentiable plasticity（2018）](https://arxiv.org/abs/1804.02464) 已通过外层梯度优化塑性机制。[Minimal motifs for habituating systems（2024）](https://pmc.ncbi.nlm.nih.gov/articles/PMC11474051/) 已系统研究慢记忆与非线性读出产生的习惯化。可微、局部误差更新、慢变量本身都不作为本轮的新意。
- [Flow-Lenia（2025），参数嵌入部分](https://arxiv.org/html/2506.08569v1#S3.SS1) 已让局部参数随守恒物质迁移、混合。当前候选关注非守恒身体的新生密度如何继承可学习状态，以及复制路径如何决定记忆保留；需要与这一近邻机制比较。
- [MetaLearnNCA（2026-10-06）](https://arxiv.org/abs/2610.08479) 提出相互作用的 NCA 和空间误差残差来实现元学习，其摘要已纳入最近工作核对。[Pandora 作者介绍](https://pajouheshgar.github.io/blog/posts/pandora-artificial-life/) 则讨论携带内部状态、位置与状态共同演化的粒子 Lenia。
- 前沿来源对未来状态贡献更大，应联系 [Gene surfing in expanding populations](https://pubmed.ncbi.nlm.nih.gov/17963807/) 等行波与谱系研究理解。本轮是确定性的个体内部状态复制；与基因冲浪的联系是机制类比，不能把前沿贡献偏置本身宣称为首次发现。
- [Stentor 单细胞研究（2022 年在线，2023 年卷期）](https://pubmed.ncbi.nlm.nih.gov/36435177/) 表明，个体切换时刻的差异可以产生平滑群体曲线。这里保存各相位、各干预的独立轨迹；均值用于展示定量关系，不用于判断个体是连续更新还是离散切换。
- [受体失活模型（2025）](https://pubmed.ncbi.nlm.nih.gov/40562036/) 已讨论响应达到平台后的隐性记忆积累、恢复延迟，并报告对应实验；图 6 还涉及重复训练与恢复后的加速习惯化。因此，仅有“相同即时响应、不同后续恢复”也不足以构成新方法贡献。本次核对了摘要与图注，未复核其全部模型与实验。
- [Stentor 分子机制研究（2026）](https://www.sciencedirect.com/science/article/pii/S0960982226004288) 的摘要报告，抑制蛋白合成会加快习惯化并延缓恢复；作者据此等证据区分形成与恢复的机制。当前模型中 α 与 δ 分开是设计假设，未识别这些生物过程，也未模拟细胞分裂或跨代记忆。

结果只涵盖一个 Orbium 的相位、旋转和局部状态干预。4 个相位不是 4 个独立生物，16 个旋转条件也不是 16 次独立重复，因此未计算总体置信区间。局部预测器、状态复制和防御目标由研究者指定；当前没有证明从通用规则搜索中自主发现学习，也没有比较其他身体形态。已完成上述有限核尺度和保留交换的固定轨迹敏感性，尚未检验其它复制约定与持续学习、身体反馈的相互作用。

真实局部经历和映射反转已完成首轮检验。前后差异没有被等剂量、共同身体或弱身体反馈控制消除；固定轨迹的有限算子变化扩散了贡献但未反转前后排序。跨形态推广仍未研究。

## LocalLearner闭环：局部防御下限与常数中性对照

`LocalLearner.defense` 与 `LocalLearner.step` 现接受相同的独立读出参数 `defense_floor=0.`、`defense_mode="learned"`。原概率预测与符号时钟分别产生自己的原始防御，再共用 [control_defense](defense.py) 施加读出干预；未另建环境或学习模型。

```python
# 从同一个保存的 State 副本开始，原 rule/config 不变。
state, cost, defense = learner.step(
    state, cue, toxin, defense_floor=.5,  # 学习读出的局部防御下限
)
# 独立对照分支；逐步继续 acquire 和 inherit，但防御恒定为中性值：
neutral_state, neutral_cost, neutral_defense = learner.step(
    neutral_state, cue, toxin, defense_mode="neutral",
)
```

可见区域由 `(cue > 0).any(dim=1)` 决定：任意线索通道为正时，下限模式取 `max(d,.5)`，常数中性模式取 `.5`；其余位置防御严格为0。弱正线索也触发完整下限/中性值，而非按线索幅度缩小下限。常数中性模式不依赖记忆，但继续累积真实反馈；它与只在分叉时擦除记忆不同。下限与中性模式不读取当前伤害，不修改输入身体或记忆。默认参数保留原读出。

闭环顺序仍为旧状态读防御 → 原成本律及身体更新 → `acquire` → 原内在衰减 → `inherit`。读出干预可经身体后果间接改变后续继承，不能要求分叉后的身体/记忆相同。原 `rate` 和 `inheritance` 张量覆盖接口仍可使用。此处不关闭反馈、相位或任何学习过程；符号时钟的冻结探测仍使用上一节的 `probe_step`，两种用途不能混用。

无提示位置保持零防御，但当前伤害仍按原公式 `toxin*(1-d)+κ*d²` 作用；只有 `cue=0` 且 `toxin=0` 才构成无刺激身体后续。常数中性控制也只在可见线索时生效，不能把全场持续 `.5` 防御当作这个对照。即时折半关系不用于闭环累计收益或存活判断。

[读出检查](test_defense.py)核对局部/弱线索、休息、无提示伤害、毒素不能泄漏到当前决策、常数中性独立于记忆、闭环仍学习、原更新顺序及积分器复用。与既有局部模型、积分器、时钟和环境接口检查一并通过。另用主作业 `4425d94a-b479-427d-83c5-c2f871a6d76b` 保存的两个状态作软件回归样例，8步局部线索/休息输入下，对照其归档旧模型，默认及显式零下限的身体、记忆、成本和防御逐步误差均为0；[记录及散列](results_20261016/local_defense_interface.json)。这些是接口验证，没有重跑训练或新增环境后果批次。后续环境运行的源快照需包含新增共用文件 `local_learning/defense.py`。

## 外部痕迹分支复用：状态、行动与代价合同

最小入口是 [model.py](model.py) 的 `LocalLearner.defense(state,cue,...)`（只读，返回局部防御d），以及 `LocalLearner.step(state,cue,toxin,...)`（完整闭环，返回新State、成本场L、防御场d）。二者共用同一读出；[defense.py](defense.py) 的 `control_defense` 只负责可见范围、下限和常数中性对照，不负责将环境痕迹C解码成预测，也不推进身体。当前没有C写入、扩散、读取成本或定向运动模块。

| 输入/输出 | 合同 |
| --- | --- |
| `state.body` | A，浮点张量 `[B,H,W]`，密度范围[0,1]；通常CPU float64，64×64周期Orbium |
| `state.memory` | m，`[B,2,H,W]`，两个线索身份的局部伤害预测；中性.5，保存在个体内 |
| `cue` | u，非负的 `[B,2,H,W]` 可广播场；通常一热线索，可为局部/弱接触；不是隐藏环境标签 |
| `toxin` | y，`[B,H,W]` 可广播的当前伤害暴露；已验证任务使用0/1，供身体后果及决策之后的更新使用 |
| `defense` / `cost` | d与L，`[B,H,W]`；返回的是局部控制/成本场，不是裁剪后实际组织损失 |

原读出为 `d0=clip(sum_i(m_i*u_i)/(2κ),0,1)`；正线索可见处可选择下限或常数中性控制，别处d=0。原成本为 `L=y*(1-d)+κ*d²`，身体为 `A'=clip(A+dt*(G(K*A)-b*L*A),0,1)`；κ为`defense_cost`，b为`burden`。因此动作是有代价的局部减伤场，并不提供定向力、目标位置或自主趋避。位置相关的密度改变可以间接改变运动，但不能称已实现定向行动。

完整闭环在决策之后按 `m_i += α*u_i*(y-m_i)` 更新，再施加原内在衰减和组织继承。α、κ、b、衰减、β以及3×3新生组织复制均是指定规则；其关系积累是已知的条件指数积分器，不是自主发现的新学习算法。身体保留部分保留浓度，新生部分按旧邻域密度加权复制，死亡位置恢复.5；该复制不守恒密度加权记忆。测试时所有规则固定，变化的是A和m，不是遗传参数。

**人为感觉与反馈约定：** y是外部提供的未防御伤害暴露，不是从实际组织损失估计的误差；即便防御减少了实际损伤，当前更新仍能读到同一个y。训练数据中的线索—伤害关系、共同中性防御身体、参数和收益函数均由实验者设置。当前决策不读当前y或隐藏可靠性；但反馈通道本身是指定的感觉能力。成本项不是测得的能耗，模型也没有独立感觉/写入代价。

**提前警告的限制：** 本接口没有延迟资格迹或可持续的防御状态。C若仅在风险前以cue出现，当时y=0会写入安全反馈；之后cue消失时即使m保留，d仍为0。不能仅把提前C塞入cue就宣称建立了警告→后续风险的学习。C→线索/风险预测的局部编码、何时查询以及信息如何跨时保存，都是尚需显式指定的外部适配；这不是当前已验证的接口能力。

若比较外部C与内部m的位置，应复用同一d→L→身体路径，并明确相同的决策查询窗口、局部可见范围、C→预测编码及信息来源；改变存储位置不能同时暗中改变感觉目标或防御持续时间。连续C不是两通道m的同义变量。原外部风险H若已经是共享引擎的抑制强度，不能未经换算当成这里的y：b同时缩放伤害和防御成本。原外部读取代价也不会被κd²自动涵盖，需独立定义和记账。现有`local_environment.neutral_cost`表示中性预测的原最优读出，只有κ=.5时才等于常数d=.5；常数中性动作应使用新的`defense_mode="neutral"`。

已有真实身体证据由环境组维护：[LOCAL_ADAPTATION.md闭环段](../environment_evolution/LOCAL_ADAPTATION.md#闭环反转即时减伤与过时记忆的消亡代价)。`4425d94a`在α=.15、β=1、κ=.5、b=.6下，保持关系时首个5步脉冲组织损失相对擦除减少初始质量的1.895个百分点，但双方均8/8持续活动；反转旧记忆8/8消亡、擦除/正确供体8/8活动。`b012a689`交换开场仍得到旧记忆全部消亡。这些是四条环境经历×两个确定性身体相位，不是八个独立生物；训练采用共同中性防御身体，测试才闭环，不能外推到C预警或一般生存优势。冻结时钟的成本降低与活动恶化另见该报告，不能混用两套参数与机制。

### 接口评议补充：时间、单位与可见性

已核对环境痕迹成员的 `information_264bd077e438` v1。`rate=0` 只关闭新反馈获得，原内在衰减和组织继承仍会更新m；不能称完整状态冻结。将C幅度当cue也会同时改变防御读出的增益和学习速率，不只是移动信息的存放位置。

若旧H是引擎强度，保持原无防御风险要求 `b*y=H`。设另有独立读取强度r，总强度应记为 `Q=H*(1-d)+b*κ*d²+r`。仅作同状态、单步单位诊断，沿用已有b=.6、κ=.5、H=.06，则y=.1；在单位一热线索下：

| 动作（此表r=0） | d | Q | 相对不防御的名义强度节省H−Q |
| --- | ---: | ---: | ---: |
| 不防御 | 0 | .06 | 0 |
| 原中性预测.5／常数中性动作 | .5 | .105 | −.045 |
| 已知当前真实H的分析用最优动作 | .1 | .057 | +.003 |

最后一行来自 `d*=clip(H/(2*b*κ),0,1)`，使用当前真实H，只是分析参照，不能输入实际策略；.003也不是已观察到的组织减损。实际单步损失还取决于dt、A、增长与裁剪，累计后果需要完整轨迹。没有据此修改参数、选取感觉阈值或新增实验。把y从0/1改为归一化伤害幅值后，m预测的是该幅值的条件期望，不再直接是伤害事件概率；.5仅为既定初始化/参照，不保证适合弱风险。

当前LocalLearner以 `(cue>0).any(1)` 判断可见性；非零热核尾部即使极小，也可能让floor/neutral在全域开启。进入接口前必须明确预先确定的感觉支持域/检测阈值和有效cue，不能把数学上的非零尾部等同于有效感知。若以掩膜把cue置零，读出与acquire的接触范围都会随之改变，需在合同中说明。当前未提供自动阈值，也未修改默认可见性。

“风险时仍可查询C”属于当前环境查询/环境继承；“仅早期接触C，风险时无法查询C”才要求显式跨时状态及查询约定。两者不能共用未声明的时序假设。信息关闭对照应保留同一防御能力和预定默认预测/动作，动作关闭另列；同身体、同可见性、同查询窗口和代价口径下的差异才有助于识别信息作用，避免把新增执行器本身的优势归给C。以上是接口使用限定，原固定抑制读取负结果及已发布报告不变。

[fast_slow.py](fast_slow.py)复用已保存的实际核与`DecodedEngine`/`TorchLenia.step`，只增加一个固定空间格点上的占据抑制场q。设τ以**更新步数**为单位，ρ=exp(−1/τ)，同步更新为：

```text
A[t+1] = clip(A[t] + .1 * (G(K*A[t]) - g*q[t]*A[t]), 0, 1)
q[t+1] = rho*q[t] + (1-rho)*A[t]
m[t+1] = inherit(A[t], A[t+1], m[t], beta, "growth")
```

q起始为0；身体离开后，q在原格点以τ恢复，无扩散、平流或组织继承。它是外部占据痕迹，不是新的身体内记忆通道。身体先读取旧q，q更新读取旧A；没有当前新A的隐式反馈。所有规则参数在生命期固定。g=0时定义q恒为0，使原关闭耦合轨迹可精确复用；其τ字段仅为占位。原两通道m按原β继承，本轮cue/toxin均为0、反馈关闭，m不参与身体更新。局部慢通道、恢复律及该小规模参数试探均不作新学习算法声明。

三个归档起点是V1随机起源候选b02/b04/b07-i036各自的trained状态（原life64），不是重新优化或重新训练；同一起点的A/m、实际离散核、μ/σ、dt=.1均相同。第四个初态使用b04的同一核/增长骨架，以固定seed=2026101619生成新的局域平滑密度，m初始化.5。它不与旧身体拼接，也不作为第四种独立核。每个起点比较关闭耦合，以及g∈{.75,2}×τ∈{8,32,128}，共28条件，32²、float64周期空间。

## 有限物质输运与组织携带的可塑状态：真实取食后果

本路线改变了表示。`material_transport.py` 使用有限组织密度ρ、携带能量E、两通道可塑浓度m与资格迹z；**没有ρ≤1裁剪、没有固定格点q，也没有此前的防御标量成本**。摄食减少外部有限资源并增加实际E，代谢和移动消耗E，危险与饥饿移除组织及其能量。当前没有食物转组织增殖、繁殖或定向力控制器。最小原型、共同身体干预、留出世界、撤除起点资源和信息携带对照均已实跑。整体课题仍在推进，以下是有限机制证据。

入口为 `from local_learning.material_transport import MaterialBody, Rule, State, load_state`。`model,state,snapshot=load_state(path)` 恢复完整规则与ρ/E/m/z；`model.step(state,cue,resource,hazard,plastic=True,memoryless=False)` 返回新状态与物质/能量账本。调用者从resource扣除返回的`resource_consumed`，不能再调用另一个摄食/伤害算子。ρ/E为[32,32]、m/z为[2,32,32]，float64、周期边界、dt=.1；生命期规则固定，外层分支才改变规则或初态。快照step是生命期更新数；训练时间0–24，共同测试24–72（测试自身0–48），每.8保存真实帧，无跨节点插值。

**具体局部规则。** 身体势 `P=c·Gaussian(ρ)−p·ρ²`。四邻面从i流向j的率为 `mobility·max(tanh(Pj−Pi+cue_gain·Σk m[i,k](C[j,k]−C[i,k])),0)`；乘dt后以总流出不超过.8作局部保护。ρ、E、ρm、ρz使用**同一供体通量**，浓度由输运后广延量除以输运后ρ获得。该步骤守恒各广延量；实际摄食、能量开支、组织丢失和可塑写入分别入账，不假装整个开放生命周期守恒。运动只读旧身体/内部状态和当前可见C，不读当前resource/hazard、关系名或未来标签。

输运后，实际摄食量为 `min(resource, dt·uptake_rate·ρ, max(energy_capacity·ρ−E,0))`。危险组织损失为 `ρ·(1−exp(−dt·hazard))`；低单位组织能量另外引起饥饿损失。z以时间常数.8追踪当前位置线索；发生摄食或危险接触时，用实际单位组织摄食/伤害的 `tanh(5·摄食率−25·受伤率)` 更新各线索m，局部更新率由z决定，m另有时间常数200的衰减。这是**预设感觉价性与局部学习公式**，不是模型自行发现奖惩，也不读取未发生的危险标签。运动能量开支受已有E上限限制，力没有直接因E=0关闭；饥饿通过组织损失起作用。保存帧中零能量组织比例在开发/留出/空隙测试最大分别为.03894%/.00539%/.000695%，仍应保留这一表示限制。
