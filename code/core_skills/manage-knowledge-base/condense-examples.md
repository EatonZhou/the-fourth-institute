# 使用示例

## 预览一次知识库凝练

> “检查 FlowTango 知识库中是否有过于冗长的条目，先不要写回，只给预览。”

> “对 FlowTango 的决策条目执行一轮语言凝练，输出差异摘要。”

> "找 3 个可以安全精简的知识库条目，保持原意完全不变。"

## 凝练单个条目

> “凝练 `${share_root}/Projects/FlowTango/knowledge_base/decision/xxx.md`，先展示改动。”

> “这个 Markdown 条目太冗长了，在不改变原意的情况下压缩正文。”

> “保留 YAML 头部，只改正文，让这个知识库条目更紧凑。”

## 写回修改

> “刚才预览的第一条可以，应用到原文件。”

> “直接修改这个文件，但必须保留原意和 YAML 头部。”

> "对这 2 个候选执行写回，其他跳过。"

## 批量前小样本

> "先在 LSSPerspective 里挑 5 条试跑，看看压缩质量。"

> "用小样本验证一下知识库凝练规则，不要全库改。"

## 质量检查

> "检查这次凝练有没有改变原意。"

> "对比原文和凝练版，看看有没有删掉关键约束或职责边界。"
