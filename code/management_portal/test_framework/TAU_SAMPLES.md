# TAU 公共提示与辅助函数固定样例

TAU 每次产出使用报告，说明过程、按产品问题／用例问题／执行偏差／工具问题分类的问题清单，以及性能体验。问题分阻断、影响使用、小问题。计时、截图、因果关系缺失时注明“未记录”；可补充观察并说明补记时间。发布或重启期间能自行恢复的短暂错误记入过程，只有不能恢复的实际影响才记产品问题。辅助工具的自动化测试验证工具行为，其测试通过与否不用于判定一次产品使用是否成功。

在仓库根目录运行：

```sh
python3 code/scripts/check_tau_samples.py
```

使用已安装测试依赖的 Python，以及本源码树的 TAU Playwright/Chromium。pytest 沿仓库规则使用隔离数据库，浏览器使用本地 HTTP 夹具，不登录 Dev、不调用模型、不创建正式 Campaign。缺依赖、跳过、失败或超过五分钟均不算通过。命令输出用例结果、总时长和公共提示摘要，并拒绝测试期间发生的公共提示或助手源码变化。

维护规则由 `decision_c953eab654cd` 定义。每次修改公共提示或测试辅助函数，在发布和下一次正式 Run 使用前运行整个固定组，并保留原输出。新问题先补能复现失败的检查；修复检查在修复前源码上失败、修复后通过。测试夹具应加载原生模板、组件和事件，不为使新条件通过而手造产品没有的字段。

提示是自然语言，固定组不宣称能自动理解任意改写。审查者逐项将新增或改变的等待条件映射到原生样例：字段来源、显示入口、加载到完成的过程、正确身份与失败分支均须覆盖。缺少对应页面能力时先纠正提示。已知 Session 错误另有精确旧措辞回归检查；这项检查只防止原错误原样回归，不能代替新提示的行为样例。

这些样例验证测试方法。正式 TAU 像用户一样完成流程，记录实际体验；不要求完整证据链，不因缺少截图或计时重跑用例。原有观察保留，后续补记明确注明时间和来源。
