# TAU 公共提示与辅助函数固定样例

在仓库根目录运行：

```sh
python3 code/scripts/check_tau_samples.py
```

使用已安装测试依赖的 Python，以及本源码树的 TAU Playwright/Chromium。pytest 沿仓库规则使用隔离数据库，浏览器使用本地 HTTP 夹具，不登录 Dev、不调用模型、不创建正式 Campaign。缺依赖、跳过、失败或超过五分钟均不算通过。命令输出用例结果、总时长和公共提示摘要，并拒绝测试期间发生的公共提示或助手源码变化。

| 行为 | 固定验证 |
|---|---|
| Chat ready 与身份 | 原生 Chat 的头部、输入框、加载状态；正文中相同 ID 和 Loading 文本不参与身份判断；隐藏、错误目标、多匹配被拒绝 |
| 完整 Session ID | 原生 lineage 页面已提供 Provider Session，Chat 仍无 Session 头部；真实 Resident Menu 显示完整值，真实复制事件取得同一值；保留旧头部硬等待的负样例 |
| 相对定位 | 原生 Family 状态表渲染在测试宿主中；`has` 的正确相对子定位匹配一处，携带外层 dialog 的旧定位匹配零处 |
| Fork 与 Editor 发现 | 实际快捷 Fork 点击只提交一次夹具指令并自动打开子 Chat；额外原生同身份 Chat 存在时先枚举候选，严格等待旧写法失败，按已发现的原 Editor ID 核验成功 |
| 菜单到表单 | HATG New node 直接打开表单；目录 Lineage 菜单还需 Attach、New Resident 两步才出现注册标题输入框；打开菜单不算表单 ready |
| Family 夹具隔离 | 真实 ISA 的隔离数据库测试仅移出临时成员，完整比较其余名册和策略，Resident 保留；角色账号 preflight 拒绝错误 Steward 且 Apply 尚未执行 |
| 终态读取 | 原 Trigger Path 在输入完成后仍 running 时继续只读同一 ID；页面快照区分 running/idle、错误节点与隐藏节点，旧采样不被后续状态改写 |
| 原刷新窗口 | 提示中的实际刷新示例在区域重建后等待新的完整内容；旧 ElementHandle 不能替代当前 Locator 的 busy 状态 |

维护规则由 `decision_c953eab654cd` 定义。每次修改公共提示或测试辅助函数，在发布和下一次正式 Run 使用前运行整个固定组，并保留原输出。新问题先补能复现失败的检查；修复检查在修复前源码上失败、修复后通过。测试夹具应加载原生模板、组件和事件，不为使新条件通过而手造产品没有的字段。

提示是自然语言，固定组不宣称能自动理解任意改写。审查者逐项将新增或改变的等待条件映射到原生样例：字段来源、显示入口、加载到完成的过程、正确身份与失败分支均须覆盖。缺少对应页面能力时先纠正提示。已知 Session 错误另有精确旧措辞回归检查；这项检查只防止原错误原样回归，不能代替新提示的行为样例。

这些样例验证测试方法，不替代正式 TAU 的原始业务、性能、截图、首次刷新或清理证据，也不回填历史 Run。
