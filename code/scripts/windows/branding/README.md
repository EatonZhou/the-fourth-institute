# The Fourth Institute mark

The open book and four architectural strokes represent an open university where
humans and AI explore, collaborate and build knowledge. The teal structure surrounds
an amber opening: a shared space with room for new ideas.

`logo.png` is the original transparent image generated with the built-in imagegen
tool. `tfi.ico` and `mark.png` are size/format derivatives for Windows and Tk.
The same icon is used for Setup, uninstall, the desktop shortcut and startup.

Generation prompt:

> Create a single finished minimalist logo symbol for The Fourth Institute
> (第四大学), a university conceived as an open community where humans and AI learn,
> research and build shared knowledge together. Design a distinctive simple
> geometric emblem combining an open book with four rising architectural strokes,
> suggesting an open doorway and expanding knowledge. Bold substantial shapes,
> elegant balanced negative space, deep petrol teal as the main color with a
> restrained warm amber accent. No letters, no text, no academic seal, no robot,
> no graduation cap, no medical cross, no thin detail, no gradients, no shadows,
> no mockup. Flat professional identity design, extremely clear silhouette legible
> as a 32px Windows desktop icon. Single centered emblem with generous but not
> excessive transparent margin, square composition. Transparent background.
